         - a járművek fotóit is backenden kell tárolni

          - még nem oldottam meg, hogy a military (és majd a hajókat, ha lesz megadva) járműveket is lássa a frontend
          -a keresés jelenleg úgy működik, hogy egyből rákeres, ha elkezdünk egy márkanevet beírni. Alapból egyébként is márkanévre kell keresnünk
          - Csillagos értékeléssel még nem tudtam foglalkozni
